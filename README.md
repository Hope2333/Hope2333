## About

I study **Digital Media Art** and am building toward a **Technical Artist** role: the space between visual creation, animation systems, tooling, and low-level engineering.

My current work sits in three overlapping areas:

- **Technical art and animation tooling**: 2D animation, creative pipelines, graphics-adjacent C++ work, and artist-facing workflow improvements.
- **AI-assisted development systems**: OpenCode/agent workflows, long-term AI coordination, model routing, and reproducible toolchains.
- **Linux, Android, and Termux engineering**: packaging, runtime adaptation, shell automation, and making serious development tools run in constrained environments.

I like projects where the interface between art and engineering is not abstract: animation tools, creative production scripts, Android/Linux runtimes, and AI systems that can actually help build things.
